# サイト内検索 ARG 記事一覧

`src/arg/articles.ts` の `ARTICLES` に定義されている、サイト内検索から閲覧できる記事の一覧。
実装・キーワードの追加/変更を行う際はこのファイルも合わせて更新すること。

## 記事の見つけ方（重要な仕様）

- 記事はトップページの「サイト内検索」窓にキーワードを入力することでのみ表示される。
- 記事本文中に登場する `arg-hint` は次に検索すべきキーワードを示すマーカー用のクラスだが、視覚的な装飾（色付け・下線等）は持たず、地の文と見分けがつかない。クリックによる自動検索・自動遷移も行わない。
  ユーザーは自分で本文を読み込み、重要そうなキーワードに気づいて検索窓に手入力する必要がある
  （調べる楽しみを損なわないため、ヒントの強調表示・記事間の自動リンク遷移は意図的に廃止している）。
- `unlock: true` の記事（開業のご挨拶）は検索ワードを持たず、お知らせセクション内の `data-article` リンクからのみ到達できる。
- サイトマップ（`SiteMap.vue`）のピンにある「サイト内で詳細を検索 →」ボタンは、地図上に表示されている観光情報記事（D〜O）に限り検索欄へのジャンプ・自動検索を行う。これは物語のヒント連鎖とは別系統の、地図UIとしての利便機能。

## データ構造・実装メモ

- 記事定義: `src/arg/articles.ts`（`Article` インターフェース、`ARTICLES` 配列、`searchArticles()` / `getArticleById()`）
- 検索UIロジック・モーダル表示: `src/arg/search.ts`（`initSearch()` / `openArticleModal()`）
- モーダルのマークアップ: `src/components/arg/ArticleModal.vue`
- 記事本文中のクラス:
  - `.arg-hint`（`data-keyword` 属性付き）: 次に検索すべきキーワードを示すマーカー用クラス。視覚的な装飾（色・下線等）は持たず、クリック動作も持たない（地の文と同じ見た目）。
  - `.arg-redacted`: 黒塗り表現。ホバーで一時的に文字色が変わり読める（`src/style.css` 内 `.arg-redacted:hover`）。
