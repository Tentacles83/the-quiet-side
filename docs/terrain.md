# 周辺地形メモ（御鏡湖エリア）

アクセスマップ（画像化・イラスト化）を作る際に地形・位置関係がブレないよう、
`src/data/mapMarkers.ts` と `src/assets/site-map-base.svg`、`src/arg/articles.ts` の記述から
現状の設定を一つにまとめたもの。マップ画像を新調する場合もここに書かれた位置関係・方位・距離感を踏襲すること。

## 1. 全体構成

- 中央〜南寄りに **御鏡湖**（周囲約8km、最大水深15m、標高約900m）が広がる。
- 湖の**北側**に山系（**鏡山** 1,340m、**御鏡山** 1,280m、名称なしの峰2つ）が連なり、盆地を囲む。
- **御鏡ヴィラ**は湖の北岸、山々の裾野が終わるあたりに位置する（山と湖に挟まれた立地）。
- 温泉・寺・神社は湖の**西岸〜南西**に点在し、直売所・駅・ICは湖の**南東〜東側**に位置する（＝ヴィラから見て観光エリアは西寄り、交通の玄関口は南東寄り）。
- 地図の方位は北を上（コンパスは右上に配置）。縮尺バーは目安として 0〜1km〜2km（イラストマップとしての簡略表現であり、正確な実測ではない）。

## 4. 地図画像化のためのAIプロンプト

ユーザー提示のイラストマップ（水色の海・グレーの道路線・オレンジの星マーク・丸ロゴ・手書き風の温かみのあるタッチ）と同系統のスタイルを想定したプロンプト例。

```
のどかで手描き風の観光案内イラストマップを描いてください。

【全体スタイル】
・水彩とペン画を掛け合わせたような、温かみのある手描きタッチの案内図
・実写ではなくイラスト調（観光パンフレットやホテルの周辺案内でよく見る簡略化されたマップ）
・背景は生成り色〜クリーム色の紙、道は細いグレーの線、水面は淡いブルー
・キャンバス比率は横800:縦760（正方形に近い縦長）

【構図・地形】
・中央〜やや下寄りに「御鏡湖」という湖を描く（湖岸線はなめらかな曲線、水面に薄い光沢）
・湖の北側（画面上側）に山並みを2〜4峰、稜線をなだらかに描く。山頂に薄い雪冠、山肌に等高線を軽く入れる
・湖の北岸、山のふもとに「御鏡ヴィラ」（丸いロゴマークと星印つきの目立つピン）を配置
・湖の南東（画面右下方向）から「御鏡IC」と「御鏡駅」への道が伸び、地図の右下の角に位置する
・湖の西〜南西（画面左下方向）に「御鏡温泉」「光明院」「鏡山神社」を点在させる
・湖の南（画面下寄り）に「山の幸直売所 みどり」を配置
・山の中腹（ヴィラの北西あたり）に「御鏡湖展望台」を配置

【道路表現】
・自動車道（IC方面）は太めの線で強調し、黄色のセンターラインを入れる
・国道・湖畔道路は白〜クリーム色の細い道として描き分ける
・湖を一周する点線のサイクリングロードを描く

【装飾・アイコン】
・各スポットは丸いドットまたは小さな絵文字風アイコン（神社の鳥居、寺の卍、温泉マーク、山小屋アイコンなど）で表現
・目印になるスポットには橙色の星マークを添える
・右上に方位磁針（Nの文字付き）、左下にスケールバー（0〜1km〜2km表記）を配置
・全体的に暖色と寒色（陸の生成り色×湖の水色×山の緑）のバランスが取れた、優しく懐かしい雰囲気に

【避けたいこと】
・写実的・3DCG的な質感
・都会的・近未来的な要素
・実在の地名や商標のロゴ
```

**補足**：AI画像生成は日本語テキストの描画精度が低いことが多いため、地名・施設名のラベルは生成後に別レイヤー（Figma/Illustrator等）でテキストを重ねるのがおすすめです。上記プロンプトではラベルの位置関係や地物の配置を指示し、実際の文字入れは後工程で行う想定です。

## 5. 手直し（img2img）用プロンプト

初回生成後、位置関係のズレを修正するために使ったプロンプト。同じ画像を元にした編集・再生成に利用する想定。

```
この地図イラストを元に、以下の点だけを修正してください（全体の画風・配色・構図はそのまま維持）。

【位置関係の修正】
・「鏡山神社」を、現在の左端（光明院・御鏡温泉のすぐ下）から、湖の南側・「山の幸直売所 みどり」の左上あたりへ移動してください。
　方角の並びは、湖の西から南にかけて反時計回りに「御鏡温泉→光明院→鏡山神社→山の幸直売所みどり」の順になるようにしてください。
・「御鏡湖展望台」を、現在の山のふもと（湖と同じ高さ）から、もう少し山の中腹（標高が高い位置）へ引き上げてください。

【道路の修正】
・黄色い高速道路（早霧自動車道）が地図右上の方位磁針側で画面の外へ切れているので、代わりに湖の東岸あたりで自然に終端させ、湖畔の道につながるように描き直してください。
・早霧自動車道の線に沿って小さく「早霧自動車道」、白い一般道の線に沿って「国道482号」という文字ラベルを追加してください。
・線路（早霧鉄道）は御鏡駅で行き止まりの終着駅であることが分かるよう、駅の先で途切れさせ、画面外まで伸ばさないでください。
・湖を一周する点線のサイクリングロードを、現在の黒っぽい点線から緑色の点線に変更してください。
・御鏡ヴィラから御鏡湖展望台へ向かう小道を、他の車道と区別できる茶色の破線（登山道）で描いてください。

【変更しないでほしい点】
・全体の手描き水彩タッチ、配色、御鏡湖・山並み・御鏡ヴィラのロゴ、コンパス、スケールバーのデザインはそのまま維持してください。
```

上記を反映した画像では、展望台の標高・高速道路の終端・道路ラベル・サイクリングロード（緑破線）・登山道（茶破線）は修正されたが、**鏡山神社が依然として御鏡温泉・光明院と同じ西端にクラスターしたまま**（南側へ移動できていない）。

## 6. 画風変更版プロンプト（線画スタイル）

水彩イラスト調が「AIっぽい」と感じられたため、参考画像（白背景・細い黒線・最小限の色数の手描き案内図）のテイストに合わせて全面的に描き直す用のプロンプト。鏡山神社の位置修正もここに統合済み。img2imgではなく新規生成として利用する想定。

```
手描き風の観光アクセスマップを、以下のスタイルで描いてください。

【全体スタイル（重要）】
・背景は白〜生成り色のフラットな紙。陰影・グラデーション・水彩の滲みは使わない
・道路・地形はすべて細い黒の一本線（輪郭線）で表現し、立体的な塗りは避ける
・色数を絞り、基本は黒線＋最小限のアクセントカラー（水域の水色、星マークの橙色、ロゴの色程度）に留める
・山や森は写実的に描き込まず、簡略化した輪郭線か、小さな山のピクトグラムで表現する程度にとどめる
・雲、笑顔の木、船などの装飾イラストは入れない。情報の視認性を優先したシンプルな案内図にする
・フォントはシンプルなゴシック体

【構図・位置関係（この配置のまま描く）】
・中央に「御鏡湖」（輪郭線＋薄い水色のベタ塗り、グラデーションなし）
・湖の北側に山並みの輪郭を簡略に描き、そのふもと・湖の北岸に「御鏡ヴィラ」（丸いロゴマーク）
・山の中腹、ヴィラより奥・高い位置に「御鏡湖展望台」。ヴィラから展望台へ茶色の破線（登山道）を引く
・湖の西に「御鏡温泉」、その南に「光明院」
・「鏡山神社」は光明院の下ではなく、湖の南側・「山の幸直売所 みどり」の左上あたりに独立して配置する（御鏡温泉→光明院→鏡山神社→山の幸直売所みどりの順で、湖を反時計回りに並ぶように）
・湖の南に「山の幸直売所 みどり」
・湖の南東に「早霧自動車道」（黒線＋道路名ラベル、または国道番号のような小さな丸バッジ）と「御鏡IC」
・その南（さらに手前）に「早霧鉄道」の線路（点線か線路アイコン）と終着駅「御鏡駅」。線路は駅の先で途切れさせる（行き止まりの終着駅として描く）
・湖を一周する緑色の点線でサイクリングロードを描く
・国道482号のラベルも残す

【アイコン・装飾】
・各施設は小さな丸ドット＋簡単なピクトグラム（鳥居＝神社、卍＝寺、温泉マーク、車＝IC、電車＝駅）で表現
・目印になる地点には橙色の星マークを添える
・右上に方位（矢印＋"N"、簡易でよい）、左下にスケールバー（0〜1km〜2km）

【参考にしてほしいテイスト】
・添付した「Villa Shirahama」風の、白背景・細い黒線・最小限の色数の手描き案内図をテイストの基準にする
```
